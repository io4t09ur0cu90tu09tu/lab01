## Основи функціонального програмування у Python

### Варіант 12 — Складський облік

## Мета

Реалізувати обробку складських товарів у функціональному стилі.

Програма:
- визначає товари, які потрібно дозамовити;
- розраховує кількість товару для поповнення;
- розраховує вартість поповнення;
- застосовує оптову знижку;
- не змінює вхідні дані;
- використовує `Callable` для параметризації політик.
